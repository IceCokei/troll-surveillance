## ✨ New

1. **Language-specific screenshots** — `docs/screenshots/en/` and `zh/`; README.md shows English UI, README.zh-CN.md shows Chinese UI.
2. **Automated releases** — tagging `v*` now packages the source tarball, writes a checksum and publishes the release from `docs/releases/<tag>.md`.
3. **Release notes template** — `docs/RELEASE-TEMPLATE.md` with fixed sections, list styles and an emoji map.

## 🐛 Fixes

- English mode no longer leaks Chinese: tool matrix, device page, live device card, authors page and exploit page are fully translated.
- Tool, TrollStore and exploit entries carry `noteEn`, so notes switch with the language.
- Light mode no longer washes out content: the two `from-background` overlays are gone and contrast was raised for tables and chips.
- Badges follow the theme (`bg-background text-foreground`) instead of hard-coded dark pills.
- `nav.exploits`, `profile.title` and several page keys were missing from the dictionary.

## 🚀 Features

- CI now runs `build` plus a docs sanity job (literal escape sequences, odd backtick count, markdownlint).
- `scripts/release.sh` packs, checksums and publishes locally; the new workflow does the same on GitHub.
