## ✨ New

1. **Release body from commits** — the auto pipeline now writes `docs/releases/vX.Y.Z.md` from conventional commits before tagging, so every automatic release keeps the house format.
2. **Empty-section handling** — a section with nothing to report renders a single `—` instead of a fake placeholder line.
3. **Raw-subject fallback** — if a range only holds `chore` / `ci` / `docs`, the commit subjects are listed so the body is never blank.

## 🐛 Fixes

- v0.2.5 shipped with only “Full Changelog” because no notes file existed; both v0.2.5 and v0.2.6 are backfilled.
- `gen-notes.mjs` no longer emits a stray escaped newline that broke the file.

## 🚀 Features

- `scripts/gen-notes.mjs` is reusable locally: `node scripts/gen-notes.mjs 0.2.9` before tagging.
- The release workflow still validates the body (`check-release-notes.sh`) before uploading the tarball and checksum.
