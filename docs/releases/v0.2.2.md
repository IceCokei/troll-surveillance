## ✨ New

1. **Version-bump releases** — merging a `package.json` version change to `main` now tags and publishes automatically, no manual tag needed (`?ref` tags still work).
2. **Duplicate guard** — a run for an already-published tag exits early with a notice instead of failing.
3. **Tag/version guard** — the workflow fails if the release tag and `package.json` version disagree.

## 🐛 Fixes

- The release workflow now checks out full history so `git archive` and tag creation work.
- Notes validation errors are surfaced before packaging, not after upload.

## 🚀 Features

- Releases keep the same body format: `✨ New` (numbered), `🐛 Fixes`, `🚀 Features`, Chinese inside `<details>`.
- Every release still ships `troll-surveillance-<version>.tar.gz` plus a `.sha256` checksum.
