## ✨ New

1. **Notes are generated from commits** — `scripts/gen-notes.mjs` reads conventional commits since the last tag and fills this template, so an automatic release never ships a bare changelog link.
2. **Fallback line** — when a range only contains `chore` / `ci` / `docs`, the raw commit subjects are listed instead of an empty body.
3. **Auto release chain** — `main` push → patch bump → notes → tag → publish, verified end to end on v0.2.5 and v0.2.6.

## 🐛 Fixes

- Releases triggered by the bot no longer fall back to `--generate-notes` (which produced only "Full Changelog").
- `gen-notes.mjs` writes valid UTF-8 bullet lists instead of an escaped newline breaking the file.

## 🚀 Features

- Every generated body keeps the house format: `✨ New` numbered, `🐛 Fixes` and `🚀 Features` bulleted, Chinese inside `<details>`, install steps only in the README.
- The release workflow still validates the body with `scripts/check-release-notes.sh` before uploading assets.
