## ✨ New

1. **Auto version bump** — code merged to `main` now bumps the patch version, tags and publishes without manual intervention.
2. **Scope-aware releases** — the bump only fires on `app/`, `lib/`, `components/` or `scripts/` changes, and never on the release commit itself.
3. **Language from `x-lang`** — every page resolves language from the middleware header, so `?lang=en` works on first visit.

## 🐛 Fixes

- Light mode keeps the digest terminal dark (macOS semantics) instead of dark text on a white panel.
- Digest no longer lists duplicate dates such as `2026-10-24.en`.
- `digest.terminal` / `digest.reading` labels resolve instead of printing raw keys.
- `auto-sync every 600s, 下次 05:10` no longer mixes languages.
- Reading view verdict label follows the language (`verdict` / `今日结论`).

## 🚀 Features

- English digest is generated next to the Chinese one (`data/digests/<date>.en.md`) and served when `lang=en`.
- Item cards, filters, authors, sources and exploit labels are fully bilingual.
