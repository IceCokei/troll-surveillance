## ✨ New

1. **Auto version bump** — code merged to `main` bumps the patch version, tags and publishes automatically.
2. **Release notes from commits** — `scripts/gen-notes.mjs` turns conventional commits into this exact format, so auto releases are never a bare changelog link.
3. **i18n audit script** — `scripts/audit-i18n.py` counts Chinese leaking into `?lang=en` pages, with `--strict` for CI.

## 🐛 Fixes

- Apple security notices and ipsw firmware summaries now store an English base string and are restored to Chinese for `lang=zh`.
- Home table headers (`状态`/`条数`/`时间`) and the `queued (轮换中)` source note follow the language.
- Author roles fall back to a neutral English label instead of leaking Chinese from the dossier.
- Digest dates no longer list `2026-10-24.en` as a second day.

## 🚀 Features

- English digest generated beside the Chinese one (`data/digests/<date>.en.md`).
- Terminal stays dark inside the light theme, macOS-style, instead of dark text on white.
