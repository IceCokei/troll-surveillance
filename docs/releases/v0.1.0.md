## 🌱 First release

1. **Multi-source monitoring** — X via r.jina.ai (no API key), GitHub API + commits.atom, RSS, The Apple Wiki, ipsw.me, Apple security releases.
2. **Verdict engine** — keyword scoring, version extraction and SoC matching, outputting `direct / future / obsolete` plus an actionable flag.
3. **Live devices** — usbmuxd enumeration with per-device jailbreak and TrollStore conclusions.
4. **Daily digest** — markdown archive rendered as terminal and reading views.
5. **Interface** — Linkify skin, Aeonik Pro, grid and noise background.

- None yet — first release.
